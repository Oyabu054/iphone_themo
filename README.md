# refractory-scope

float glass製造炉内のレンガ表面温度分布(想定温度帯 1400-1600℃)を、iPhoneのブラウザカメラでその場確認するための単一HTMLアプリです。

- 絶対温度の校正は行わず、R/G(またはR/B)チャンネル比を疑似カラー化した相対分布のみを表示します
- ブラウザの `getUserMedia` API を直接利用するため、アプリの追加インストールは不要です
- `getUserMedia` はトップレベルのHTTPSページでのみ動作するため、GitHub Pages等での公開が必要です

## 使い方

1. `refractory-scope.html` をブラウザ(iPhone Safari推奨)で開く
2. カメラ許可を承認し、シャッターボタンで撮影
3. 画面タップで、その点の比率値と相対レベルをHUD表示
4. 「質感合成」スライダーで元の輝度と疑似カラーをブレンド
5. 必要に応じてPNG保存、R/G ⇔ R/Bモード切替
